# Spinscore-Website
A online store developed as a group for users to brose and purchase CDs and vinyl records through and accessible interface.

# Overview
This app is a functional music store website created as part of a group software development project. 

The app allows users to browse available CDs and vinyl records, add these items to a cart and review them before checking out.

This website also contains an accessibility mode to make it easier for users to navigate.

# Features
- Browse CDs and Vinyls
- View details of products
- Add and remove items from the cart
- Calculate total cost of items
- Complete the checkout process
- Accessibility mode
- Write reviews of the site
- Contact the developers of the site
- Responsive and user friendly interface

# Technologies
- HTML
- CSS
- JavaScript

# Accessibility
An accessibility mode has been added for users to navigate the site if they have trouble seeing the original presentation of the site.

# Running the Website
1. Clone or download the repository
2. Open the project folder
3. Open the "index.html" file in a web browser
